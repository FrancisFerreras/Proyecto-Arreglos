# Sistema de calificaciones en C++

## Descripción
Programa de consola que administra cinco calificaciones mediante un arreglo en C++.

## Objetivo
Practicar arreglos, índices, ciclos, condiciones, cálculos y modificación de elementos.

## Lenguaje utilizado
C++.

## Funcionalidades
- Mostrar las calificaciones con sus índices.
- Consultar una nota por índice.
- Calcular promedio, nota mayor y nota menor.
- Contar aprobados y reprobados (aprobación desde 70 puntos).
- Modificar una nota y mostrar el arreglo actualizado.
- Validar índices y notas ingresadas.

## Instrucciones para ejecutar
1. Guardar el código como `actividad.cpp`.
2. Compilar con un compilador de C++, por ejemplo: `g++ actividad.cpp -o actividad`.
3. Ejecutar en Linux/macOS con `./actividad`; en Windows, ejecutar `actividad.exe`.
